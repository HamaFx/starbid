# Phase 4 Completion

Phase 4 now includes:

- Rate-limited public stars and bid-events APIs
- CORS support for read-only API consumers
- iframe and script-based read-only embeds
- Claim-token-protected owner analytics
- Owner analytics history for 7, 30, or 90 days
- Aggregate outbound-click and bid-event reporting
- Conservative moderation-signal storage for future review workflows
- LOD and low-end device safeguards for large galaxies
- DEMO and Founding visual treatment
- Single-galaxy default preserved

The following remain intentionally out of scope until production usage justifies them:

- Automated bans or irreversible moderation decisions
- Crypto payments
- Multiple active galaxies
- Ranking decay experiments
- Paid analytics billing

These require real abuse, traffic, or revenue data and should not be enabled speculatively.
